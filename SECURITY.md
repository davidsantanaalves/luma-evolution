# Security policy

## Scope and support

This policy covers the LG Luma Evolution project, its native launcher and helper code, and its build and packaging tools. Report issues against the current `develop` branch and include the affected commit or build identifier.

The project is in development. The P01–P03 desktop previews have been accepted. Validation of the native webOS package and physical Magic Remote behavior is pending.

## Reporting a vulnerability

[Report a vulnerability privately on GitHub](https://github.com/davidsantanaalves/luma-evolution/security/advisories/new). Include the affected component, commit or build, environment, impact, and steps to reproduce. Remove credentials and personal information from any logs or attachments.

Use the private report for follow-up and coordinate any public disclosure with the maintainer.
